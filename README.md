# Template 4 — Brave Story (The Magnolia Private Residences)

Landing page scroll-story một trang, bố cục & motion theo mẫu studio-brave.webflow.io.

**Công nghệ:** HTML/CSS tĩnh + GSAP 3.12.5 (ScrollTrigger) + Lenis 1.1.13 (CDN). Không build.

**Section:** Hero (chữ lật 3D, tách đôi khi cuộn) → (01) Về dự án → (02) Kiến trúc (3 dòng chữ lớn 001–003) → (03) Tiện ích (ảnh co 100%→50%, mỗi nhịp cuộn mở một tiện ích, đổi ảnh, bộ đếm 01/05) → (04) Không gian (Lưới / Danh sách, ảnh nổi theo chuột) → (05) Vì sao chọn (nền ghim + thẻ vẽ viền) → (06) Khoảnh khắc (ảnh viên thuốc) → Footer (marquee 2 chiều, vòng chữ xoay, hotline).

**Chạy:** mở `index.html` hoặc `npx serve .`

**Deploy Vercel:** Add New → Project → chọn repo → Framework Preset **Other**, để trống Build Command / Output Directory → Deploy. Push lên `main` là tự cập nhật.
